Secure SD-WAN SLA probe class-ID and congestion

Fortinet's Administration Guide describes assigning a class ID to SD-WAN health-check probes to prioritize them under congestion. Probe starvation can produce false health-check failures. Configure traffic-class and shaping profiles and match the class ID in the health-check, then compare probe loss and jitter with and without congestion. Primary source: https://docs.fortinet.com/document/fortigate/8.0.0/administration-guide/941705
