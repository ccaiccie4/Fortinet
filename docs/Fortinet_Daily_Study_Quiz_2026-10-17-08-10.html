1. FortiGate — Proxy TCP BBR vs CUBIC

BBR models bottleneck bandwidth and minimum RTT. In proxy mode FortiGate terminates one TCP leg and initiates another; the global setting does not rewrite arbitrary forwarded endpoint congestion control. Verify matching proxy policy, new connections and same-path A/B throughput and retransmissions.

2. FortiManager — RBAC script target intersection

Execute Script Read-Write is necessary but not sufficient. Device/CLI targets also need Manage Device Configurations; ADOM targets need Policy Package & Objects. Custom pre-7.6.4 admin profiles receive None for the new rights, so test after upgrade.

3. FortiAnalyzer — Report Guidance dataset lineage

A chart or macro queries an Analytics dataset requiring a particular log type and fields. Raw log presence does not prove SQL eligibility. Use Report Guidance to identify required device type, log subtype and fields, then test the dataset in the intended ADOM.

4. FortiSwitch — DCBX/ETS/PFC priority groups

FortiSwitchOS 8.0 supports ETS and PFC on listed data-center models. Queue-to-priority-group mapping, dot1p trust and LLDP DCBX TLVs must align. Weighted group allocations total 100%; LLDP advertisement alone does not prove lossless runtime behavior.

6. FortiNAC — Persistent Agent DNS SRV selection

Agent server selection combines DNS SRV priorities with cached HomeServer and lastConnectedServer values. A successful TCP 4568 handshake does not prove server-certificate identity. Compare production/isolation DNS suffix, chosen FQDN and server-side host record.

7. FortiNAC-F — KEA isolation DHCP

FortiNAC-F 7.6 uses KEA for internal isolation DHCP. Registration VLAN assignment, DHCP relay, DORA exchange, portal DNS and post-registration production reauthorization are distinct boundaries. Do not edit unsupported internal KEA files.

8. FortiAuthenticator — RADIUS proxy realm and integrity

Proxy mode preserves the incoming credential method. Include realm in username supports federated RADIUS routing. Requiring response Message-Authenticator can reject a reachable upstream server response that lacks the expected integrity attribute.

9. FortiPAM — Smart Association credential lookup

At launch FortiPAM concatenates an account prefix and signed-in username, then finds the associated secret. With associated-credential launch enabled, the primary secret password is not used. Verify per-user lookup and target-side login separately.

10. FortiSIEM — Rule Tags for incident classification

Rule Tags classify rules, incidents and cases for search and triage. They do not alter correlation or severity. Assign tags in Rule Define Action and test a new incident to verify propagation rather than assuming historical backfill.

11. FortiSASE — Agent steering and shared NAT

A connected agent tunnel does not prove each destination enters the Security PoP; split-tunnel bypass and on-net exemption can route locally. Fortinet recommends alternate steering for more than 100 concurrent users sharing one source IP.
