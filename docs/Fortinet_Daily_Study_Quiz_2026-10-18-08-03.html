Lesson mechanisms

  1. FortiGate: IPv6 PIM per VRF separates MLD membership, RP mappings and RPF source routes; an MLD entry alone does not prove forwarding.
  2. FortiManager: SHA-256 NTPv4 requires matching Chrony key ID, bytes and HEX/ASCII interpretation; UDP replies alone do not prove clock sync.
  3. FortiAnalyzer: vSphere ingestion uses a hidden scheduled playbook, VMware parser and External-SIEM-Events device; inspect fazwatchd.
  4. FortiSwitch: QinQ nests customer C-VLAN inside provider S-VLAN; check tag order and TPID; DHCP snooping and STP are excluded.
  5. FortiAP: CAPWAP control uses DTLS; data uses clear-text, DTLS or IPsec; offload and encryption mode determine remote-AP throughput.
  6. FortiNAC: event frequency counts per element; lifetime alarms depend on a clear event; events can exist without asserted alarms.
  7. FortiNAC-F: Windows Persistent Agent WinCertCheck reads Local Computer certificate store; CNG certificate handling has limitations.
  8. FortiAuthenticator: CMPv2 enrollment validates profile ID, challenge or device identity, issuing CA and certificate usage.
  9. FortiPAM: native RDP 0x0068 signals security-level mismatch; 0x0140 signals NLA challenge failure; launch is not login.
  10. FortiSIEM: Scheduled via SQL requires ClickHouse; caps incidents at 100/run and omits trigger events from incident records.
  11. FortiSASE: File Filter is type-only and needs HTTPS deep inspection; DLP dictionary matching is a separate control.
  12. Secure SD-WAN: speed-test measured throughput must be applied to estimated bandwidth before capacity-based path selection.
