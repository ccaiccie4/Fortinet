1. FortiGate — Enhanced multicast session key for wildcard-VLAN virtual wire pairs

FortiOS 8.0 adds ingress interface and VLAN ID to the multicast session key for wildcard-VLAN VWP traffic. This prevents repeated traversal on different VLANs from collapsing into one ambiguous session. Verify the actual session table after generating the multi-pass flow; packet arrival alone does not prove correct session separation.

Default log forwarding can export to another FortiAnalyzer, syslog/CEF, or supported plugin while the client retains a local copy. Local presence proves ingestion, not downstream delivery. 4. FortiSwitch — IGMP snooping, querier, mRouter, and unknown multicast

IGMP snooping learns receiver interest per VLAN/group and prunes ports without listeners. Queries refresh membership; a FortiSwitch querier can operate when no external querier exists. Unknown multicast normally goes only toward mRouter ports when flooding is disabled. Inspect group state, querier, mRouter learning, and aging separately.

5. FortiAP/Wireless — Wi-Fi 7 Multi-Link Operation

MLO lets supported FortiAP-K radios and Wi-Fi 7 clients use multiple links. Eligibility depends on model/radio and SSID security: WPA3/OWE modes are required, and WPA3-SAE uses H2E. Enabling MLO on a VAP is insufficient unless the VAP is applied to participating radios. Association to the SSID alone does not prove multi-link operation.

8. FortiAuthenticator — SCEP enrollment and renewal lifecycle

SCEP uses a local CA plus enrollment challenge and an automatic or approval workflow to issue certificates. Renewal can revoke the old certificate. Separate transport, challenge validation, pending approval, issuance, and revocation evidence. A newly issued certificate does not prove the superseded credential can no longer authenticate.

Service health therefore depends on correct membership and upstream incident generation.
