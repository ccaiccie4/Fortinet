1. FortiGate: IPsec TCP MSS/PMTUD behavior

Standalone SVG · Editable draw.io source

IPsec adds ESP and possibly NAT-T overhead, reducing inner MTU. FortiOS 7.6.1 through 8.0.0 changed automatic TCP MSS handling and relied on PMTUD. Capture SYN/SYN-ACK MSS, DF packets and ICMP Fragmentation Needed before setting a measured policy MSS. IKEv2 fragmentation is a different control-plane feature.

2. FortiManager: JSON API bearer key and source authorization

Standalone SVG · Editable draw.io source

REST API Admin bearer keys persist until regeneration; session-based JSON API login uses a session ID. Both require appropriate JSON API mode, Admin Profile and ADOM authorization. Trusted Hosts and optional PKI Group restrict source and identity, except Automatic Register can bypass Trusted Hosts for that REST API Admin.

3. FortiAnalyzer: Syslog normalization into fabric logs

Standalone SVG · Editable draw.io source

Raw syslog visible in Log View Syslog is not proof of normalized fabric logs. A matching enabled parser must extract fields into siemdb. Validate the raw record, Assigned Parser and Log View All before investigating alert handlers. Generic SYSLOG fallback may preserve a message without useful normalized fields.

Fortinet primary documentation

4. FortiSwitch: RADIUS dynamic ACL Filter-Id hardware enforcement

Standalone SVG · Editable draw.io source

After 802.1X success, RADIUS Filter-Id can select a hardware DACL. Port-based mode applies to a physical port; MAC-based mode to an authenticated source MAC. FortiSwitch documents IPv4-only support and a maximum of 45 entries per port. Verify the Access-Accept, hardware DACL and packet disposition.

Fortinet primary documentation

5. FortiAP/Wireless: Multicast-to-unicast conversion

Standalone SVG · Editable draw.io source

Multicast enhancement converts suitable wireless multicast into per-client unicast copies, often transmitted at higher rates than low-basic-rate multicast. Configure multicast-enhance under the VAP and verify AP effective settings. Compare airtime, client count and radio frames; unicast replication can be expensive at large scale.

Fortinet primary documentation

6. FortiNAC: Scheduler adapter versus port disable

Standalone SVG · Editable draw.io source

FortiNAC Scheduler tasks target host or port groups. Disabling a switch port can disconnect phones and other clients behind it, while adapter disable is more selective. Verify group membership, task execution, current endpoint location, and a tested restore path. A saved schedule does not prove action.

Fortinet primary documentation

7. FortiNAC-F: RADIUS attribute-group precedence

Standalone SVG · Editable draw.io source

FortiNAC-F Local RADIUS Attribute Groups merge device-level and logical-network attributes; logical-network values take precedence. Calling-Station-Id is required to resolve that context. Compare Access-Request identity with Access-Accept attributes before blaming downstream VLAN enforcement.

Fortinet primary documentation

8. FortiAuthenticator: LDAP bind factor selection

Standalone SVG · Editable draw.io source

FortiAuthenticator 8.0.2 LDAP Service General chooses Password-only or all configured password and OTP factors for bind. TLS success proves server transport only; successful password-only bind does not prove MFA. Test the exact factor format and user provisioning when an application begins failing binds.

Fortinet primary documentation

9. FortiPAM: Secret audit and inherited folder grants

Standalone SVG · Editable draw.io source

FortiPAM Secret Audit generates a CSV snapshot of secret access, including folder path/ID, secret ID and user/group permission. Parent-folder grants can expose child secrets. Regenerate after permission changes; consult session logs to establish actual use rather than entitlement alone.

10. FortiSIEM: Custom XML parser ordering

Standalone SVG · Editable draw.io source

FortiSIEM custom XML parser files are evaluated in order. A broad recognizer may win before a specific parser. Test displays Expected Parser versus Used Parser and extracted fields. Validate checks syntax, Test checks recognition, and Apply distributes changes to the nodes.

11. FortiSASE: Inline-CASB SaaS tenant HTTP headers

Standalone SVG · Editable draw.io source

FortiSASE Web Filter with Inline-CASB uses SSL deep inspection to insert SaaS vendor-defined HTTP tenant-restriction headers. Configure name, content, action and destination in the relevant profile/policy. Test corporate login success and personal login denial, and avoid broad overlapping agentless headers.

12. Secure SD-WAN: SD-WAN zone binding for local-in policy

Standalone SVG · Editable draw.io source

FortiOS uses SD-WAN zones as interface references for local-in policies. Older member-interface references may be rejected or lost during upgrades. Check config-error-log for -651, rebind to the zone, preserve destination-IP restrictions and test traffic addressed to FortiGate separately from forwarding.
